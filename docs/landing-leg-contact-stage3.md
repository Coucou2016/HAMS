# Landing-Leg Contact Stage 3

This stage advances the rocket recovery workflow from hydrodynamic platform motion to the pre-contact inputs required by a real four-leg landing model.

## Scope

The implemented model couples:

- Wang Zhi 2023 HAMS/Cummins time histories for heave, roll and pitch.
- Thies 2022 RETALT1 touchdown requirements and landing-leg geometry.
- A circular foot-print envelope for the four landing legs.

It does not claim to reproduce Thies Adams force histories, Yue quasi-3D strut forces, Li flexible-rigid dynamics, or Wang Actuators crushing-buffer states. Those require unpublished or non-machine-readable force-stroke, joint, and contact-state data.

## Paper Data Used

Thies 2022:

- Landing mass: `61288 kg`.
- Nominal touchdown vertical velocity: `5 m/s`.
- Touchdown vertical velocity envelope: `1..15 m/s`.
- Launcher/platform incident angle envelope: `0..10 deg`.
- Four legs, tripod configuration.
- Leg length: `8.1 m`.
- Static leg angle to hinge plane: `33 deg`.
- Paper nominal kinetic energy: `766 kJ`.
- Reported dimensioning result: nozzle clearance `570 mm`, damper deformation `420 mm`, leg force `902 kN`, spring-damper force `935 kN`.

Wang Zhi 2023:

- The deck motion input comes from `RocketRecoveryCases/Paper_WangZhi_2023/Output/RocketRecovery/wang-2023-response.json`, already generated by the local HAMS/Cummins surrogate.

Additional references are stored in the generated JSON as future implementation inputs:

- Li 2025: contact stiffness, damping, static/dynamic friction and wind-load parameters.
- Yue 2022: experimental test conditions and validation-error bands.
- Wang Actuators 2023: state-machine/rebound/crushing-buffer validation errors.
- Xie 2025: Cummins impact-platform validation data.

## Implemented Formulas

The foot-print radius is derived directly from Thies Table 4:

```text
r = L_leg cos(beta0) = 8.1 cos(33 deg) = 6.793 m
```

For a deck point at radius `r`, with small roll and pitch:

```text
z_deck = heave + roll*y - pitch*x
```

Because the exact four-leg azimuths are not published in the supplied material, the report uses a circular envelope rather than a fabricated leg layout:

```text
deck_angle = sqrt(roll^2 + pitch^2)
foot_vertical_spread = 2 r sqrt(roll^2 + pitch^2)
deck_vz = heave_dot +/- r sqrt(roll_dot^2 + pitch_dot^2)
closing_speed = v_touchdown + deck_vz
first_touch_lead_time = foot_vertical_spread / v_touchdown
```

## Next Implementation Step

The next physically meaningful module is a per-leg contact state system:

1. Use the current envelope as the deck-motion input.
2. Add explicit four leg locations only after selecting a leg azimuth convention or extracting it from CAD/figure data.
3. Start with Li 2025 contact stiffness/damping/friction for foot-ground force.
4. Add Thies linear damper/platform constants as a baseline, but report force results as a surrogate until nonlinear force-stroke curves are digitized.
5. Add Yue 2022 and Wang Actuators 2023 as validation checks for contact sequence, rebound, stroke, and force-error ranges.
