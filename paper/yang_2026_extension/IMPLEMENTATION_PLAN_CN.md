# 海上四腿火箭回收论文实施与验收计划

## 1. 论文定位

主参考范例采用杨少斐等 2026 年论文。论文不以“复刻未公开的 ADAMS/Abaqus 工程”为目标，而以公开、可复算、分层验证的方法扩展其研究：

> HAMS 频域势流水动力 + Cummins 时域记忆力 + Project Chrono 四腿接触 + 海况/喷流外载 + 双向平台反馈。

研究时间范围从触地前短时段开始，到四腿接触、缓冲、反弹或离地、平台反馈和着陆后稳定结束。动力下降 GNC、真实发动机节流和具体型号适航鉴定不在第一篇论文声明范围内。

## 2. 证据分级

所有输入必须属于下列一种类型，并写入 JSON：

| 类型 | 含义 | 可否作为严格验证依据 |
|---|---|---|
| `published` | 论文正文、表格或公式明确给出 | 可以 |
| `digitized` | 从论文图像提取，保留页码、像素框和哈希 | 可以，但需计入数字化误差 |
| `identified` | 仅在指定校准工况拟合 | 只可在冻结参数工况检验预测能力 |
| `proxy` | 公开数据缺失时的工程替代值 | 只可做敏感性分析 |

任何 `identified` 或 `proxy` 参数不得写成论文作者数据、厂家数据或真实型号参数。

## 3. 实施阶段

### M0 公开证据闭环，已完成

- 登记杨论文 Table 1、Table 2、海况标量、滤波器和设计限值。
- 从源 PDF 第 7 页重新数字化 Figure 9-11 的 9 条试验曲线。
- 审计原文公式和表格内部不一致。
- 生成源数据哈希、CSV、JSON、PNG/SVG 和文献注册表。

验收：一键流水线重建全部数据和图；原始 CSV 不被后处理覆盖；27 项当前单元测试通过。

### M1 公开降阶四腿基准，已完成，状态 PARTIAL

- 箭体保留竖向和平面倾转两个刚体自由度。
- 四个足点使用独立单边接触，产生同时、1-2-1 和 2-2 顺序。
- 仅用同时触地曲线辨识 6 个有效参数。
- 1-2-1 和 2-2 禁止重新调参。

验收：三种接触顺序正确；优化器收敛；参数来源完整；逐点 CSV 可重建。当前行程峰值误差 1.7% 到 4.0%，载荷峰值误差 6.7% 到 18.7%，但加速度峰值误差 29.2% 到 51.9%，因此不得标记完整复现。

### M2 Chrono 机构动力学主线

1. 以杨 5.2 t、2 m/s 和三种姿态建立新的 `Yang_2026_Chrono` 案例，不复用 Thies 61.3 t 结果作为杨论文结果。
2. 首版采用公开参数化四腿机构：箭体、主支柱、辅助支柱、足垫、滑移副/球铰和缓冲器均为独立 Chrono 元件。
3. 缺失几何从辨识层读取并保持 `identified`；只有获得 CAD/Adams 数据后才启用 `real_leg_mechanism` 分支。
4. 输出每腿接触状态、足端三向力、支柱轴力、缓冲行程、摩擦功、冲量和接触顺序。
5. 不带锁紧机构完成接触过程后，锁紧作为独立平台侧子模型加入，不混入触地收敛验证。

验收：力与反力误差小于 0.1%；时间轴严格递增；冲量和行程在 `dt/2` 下变化小于 5%，峰值接触力变化小于 10%；无穿透爆炸、负法向力和非物理能量增长。

### M3 HAMS/Cummins 平台主线

1. 保留 HAMS 源码不改，使用本机 GNU 构建求解箱形驳船、MARMAC 近似体和 120 m x 50 m 工程驳船。
2. 对每个主案例执行网格加密，比较附加质量、辐射阻尼、激励力和 RAO。
3. 由辐射阻尼计算 retardation kernel，并检查频率截断、窗函数、核长和时间步敏感性。
4. 用频域逆变换或独立状态空间结果验证 Cummins 自由衰减和外载冲击响应。
5. 官方 benchmark 同时报告“通过案例”和“当前编译器差异”，不使用单一最大相对误差掩盖近零量误差。

验收：工程频段网格差异小于 3%；Cummins 与频域基准主要响应峰值差异小于 5%；质量、恢复矩阵对称性和辐射耗散非负性检查通过。官方旧 benchmark 未全通过前，论文只能声明独立构建成功和限定案例回归结果。

### M4 单向海上着陆

1. HAMS/Cummins 生成平台 6DOF 时历。
2. Chrono 中甲板为 prescribed moving body。
3. 分别运行静甲板、杨滤波甲板、JONSWAP 波浪甲板。
4. 比较中心、纵向偏心和横向偏心着陆。

验收：Chrono 实际使用的甲板位姿与报告/动画逐时刻一致；四个足点的甲板速度包含转动项；同一随机种子逐位重现；不同种子只比较统计量。

### M5 双向 HAMS-Cummins-Chrono 耦合

1. Chrono 返回四足合力及关于 HAMS 参考点的完整力矩。
2. Cummins 更新平台 6DOF 状态并回传甲板。
3. 每个宏步执行固定点迭代和 Aitken 松弛。
4. 分开报告波浪基线和着陆反力增量。

验收：每个宏步残差达到平移 1 mm、转角 0.001 deg 或更严格门槛；最终回放反力重新计算的平台状态与已报告状态闭合；六分量符号和 `r x F` 单元测试通过；未闭合时只能称松耦合诊断。

### M6 王智海况与喷流扩展

- JONSWAP 使用公开的 `Hs=1.75 m`、`Tp=4.5 s`、`gamma=3`、浪向 135 deg。
- 喷流仅使用论文公开表达式或数字化时历，标记为单向外载。
- 未公开系泊参数不自行补齐；无数据时采用无系泊诊断或单独的参数敏感性组。

验收：谱积分恢复目标 `Hs`，载荷时历与数字化源在峰值和冲量上对照；平台垂荡/横摇/纵摇与论文数量级同图展示，无法匹配的自由度明确说明。

### M7 统计与动画

- 海况至少覆盖 3 个 `Hs`、3 个 `Tp`、7 个浪向和不少于 30 个随机种子。
- 输出 RMS、极值、95%/99% 分位数、足点相对速度、接触顺序概率和稳定时间。
- 动画直接读取求解器状态，不单独编写视觉运动曲线。

验收：动画时间与 CSV 一一对应；火箭竖直着陆，足垫与甲板接触几何一致；可暂停、拖动时间轴、切换工况和显示真实比例/放大运动两种模式；放大比例必须在页面显示。

### M8 论文终稿

- 正文包含方法、证据协议、分层验证、失败指标、敏感性和限制。
- 图中论文数据用灰色虚线，本模型用实线；图注标明 `published/digitized/identified/proxy`。
- 结论只引用自动验收报告中的通过项。

验收：论文中每个数值可追溯到 JSON/CSV 和生成脚本；一键流水线可重建图表；所有 `PENDING` 被计算结果或明确限制替换；最终 PDF 完成版式检查。

## 4. 当前优先级

1. 建立杨 5.2 t Chrono 参数化四腿案例，替换主论文中的两自由度动力学主结果。
2. 使用无锁紧分支解决接触时步收敛，再处理平台固定点闭合。
3. 对 HAMS 官方 benchmark 做编译器与数值差异分解，形成可发表的限定验证结论。
4. 接入 HAMS/Cummins 单向甲板后再启用双向耦合。
5. 最后加入王智 JONSWAP/喷流和批量随机海况，不提前做大规模蒙特卡洛。
